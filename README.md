# Habits API — Django + DRF + JWT

API для управления личными привычками с пагинацией, фильтрацией, правами доступа и интеграцией с Telegram‑ботом. Проект построен на Django REST Framework с JWT‑авторизацией, поддержкой фоновых задач (Celery) и оплатой (Stripe).

## 📋 Возможности

- **Регистрация и авторизация** по email с валидацией пароля.
- **Управление привычками**: создание, просмотр, редактирование, удаление.
- **Права доступа**: владелец может редактировать только свои привычки; публичные привычки доступны всем.
- **Пагинация** (по 5 элементов) и **фильтрация** списков.
- **Telegram‑бот**: эндпоинт для приёма вебхуков и модель чатов.
- **Фоновые задачи** через Celery + Redis (рассылки, отчёты).
- **Оплата курсов/подписок** через Stripe.
- **Покрытие тестами** (unittest + coverage) для CRUD и бизнес‑логики.

## 🚀 Быстрый старт
